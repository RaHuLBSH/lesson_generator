# Project instructions

- This is the Self-Evaluating Lesson Content Generator take-home assessment.
- Use Python 3.11+, LangGraph, Pydantic v2, SQLite, and pytest as described in `docs/architecture.md`.
- Keep lesson generation and evaluation independent; all six rubric checks are binary and a lesson passes only if all pass.
- Keep provider credentials in environment variables; never commit secrets or make tests depend on live LLM calls.
- Preserve the beginner audience: an Indian 12th-grade graduate with limited English and no technical background.
- Keep changes small and readable. Do not add a frontend or implement later phases without an explicit request.
- Consult `docs/implementation_plan.md` before starting a new phase.
